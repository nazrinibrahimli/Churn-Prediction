In the ChurnGuard project, I compared Logistic Regression, Random Forest, and XGBoost to predict telecom customer churn. Logistic Regression achieved the highest churn recall (0.83), catching 83% of at-risk customers, ideal for retention strategies, with 75% accuracy and 0.839 ROC-AUC. Random Forest offered the highest accuracy (79%) and non-churn recall (0.92), but lower churn recall (0.45). XGBoost balanced performance with 78% accuracy, 70% churn recall, and 0.839 ROC-AUC.
